# Cube image fixtures

The photos are organized into four folders by cube type and capture configuration. The two original device folders are treated as the two capture configurations; each configuration has its own camera and capture sequence.

| Folder | Cube | Configuration | Images |
| --- | --- | --- | ---: |
| `RubikStickered_GalaxyS24FE/` | Stickered Rubik cube | Galaxy S24 FE capture | 20 |
| `RubikStickered_GalaxyTab/` | Stickered Rubik cube | Galaxy Tab capture | 13 |
| `GANStickerless_GalaxyS24FE/` | Stickerless GAN cube | Galaxy S24 FE capture | 9 |
| `GANStickerless_GalaxyTab/` | Stickerless GAN cube | Galaxy Tab capture | 22 |

Each folder has numbered JPEGs and a `rename-map.csv` mapping the original WhatsApp filename through the earlier device-based fixture name to the new filename. Cube type boundaries were classified visually: S24 FE images 001–020 and Tab images 001–013 show the stickered cube; the remaining images show the stickerless cube.

These are multi-view photos, not labeled face scans or verified color-state ground truth. Camera angle, sharpness, framing, and illumination vary. The configuration labels identify the two capture sets, not a verified cube state or face orientation.
