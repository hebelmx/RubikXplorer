# Story 10.23: shadow sticker reader model provenance

Generated by `tools/sticker-model/train_sticker_model.py` (re-run it; do not edit by hand). Same fields as the corner
model's record (`docs/evidence/10-18/litert-model-evaluation.md`, Story 10.18).

- **Model artifact:** [`app/src/camera/debug/sticker/assets/sticker_reader.tflite`](../../../app/src/camera/debug/sticker/assets/sticker_reader.tflite) (debug camera source set only; never in release, benchmark or `cornerR8`).
- **Artifact identity:** SHA-256 `a6da207a1de63ca41aefedf14a3f024fa89963a039a0506bb1a597960ff35746` (107,848 bytes = 105.3 KB, limit < 500 KB).
- **Contract:** input `[1, 96, 96, 3]` float32 RGB in [0, 1] (the unwarped face, YUV->RGB as `CornerModelTransform.fillRgbInput`); output `[1, 9, 6]` softmax per sticker in Kotlin cell order (row-major); colour order WHITE, YELLOW, RED, ORANGE, BLUE, GREEN.
- **Confidence rule:** CONFIDENT when the top-1 probability >= tau = **0.99**, else UNCERTAIN. tau is the smallest value on the 0.50-0.99 grid giving 0 confidently wrong stickers on the tune split (none did, so the spec's fallback 0.99 applies: tau sits at the ceiling of its grid and the rule cannot raise it further): tune 162 stickers, 147 confident correct, 14 uncertain, 1 confidently wrong.
- **Recipe:** seed `20261123`, quant `fp16` (`Optimize.DEFAULT` + float16 supported type), 46,878 parameters; 24 epochs, batch 256, Adam with cosine decay from 0.003; training side only: 69 real faces from 12 groups x 120 seeded augmented copies (quarter turns with labels turned, light, tint, shift, noise) + 36,000 `synth_faces.py` faces (palettes from training groups only). Tune faces only choose tau; held-out faces are never read in training.
- **Tools:** Python 3.12.13, TensorFlow 2.19.1 and its bundled `TFLiteConverter`, NumPy 2.1.3, Pillow 11.3.0, Linux x86_64 + CUDA GPU (`tensorflow[and-cuda]`).
- **Reproducibility:** dataset assembly is byte-identical across runs; training is seeded, but GPU training is not bit-exact, so a retrain reproduces the recipe and its metrics, not the SHA-256 above. Re-run `train_sticker_model.py` and then update `StickerModelContract` (tau, SHA-256) to match `model-card.json`; `StickerModelContractTest` fails until they match.
- **Runtime:** `com.google.ai.edge.litert` (already in debug builds through the corner model), XNNPACK CPU, 4 threads, no GPU or NNAPI delegate, on the reader's own single-thread executor.
