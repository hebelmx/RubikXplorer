## Findings

Each finding has a source and a disposition: fix now, defer, or accept.

### Spec-to-implementation reconciliation

- **F1. 11.3 as-built uses two opposite corners, not one view.** The planning spec says "captures one top-corner view (U + two sides)" (`epics.md`, Story 11.3 AC1). `EXPERIENCE.md:260` says "one top-corner photo". The PO decided on 2026-11-18 that two opposite-corner captures are always required, with candidates intersected (`spec-11-3-recognize-an-oll-pll-case.md:36-38`, PR #191). The as-built is a sanctioned divergence, but the planning artifacts were never reconciled.
  - **Disposition:** fix now, as a spec reconciliation (proposed, not applied).
  - **Lesson:** a PO clarification that changes an AC's mechanics should trigger a correct-course note, not only a spec intent update.
- **F2. Placement suggestion copy differs from the UX example.** EXPERIENCE.md Flow 4 shows the example "Your cross is done and 2 of 4 corners are in. Start at *First-layer corners*?". The PO chose the plain "Start at <Stage>?" (PR #189 PO decisions; `en.json:22`). A non-white cross now suggests Stage 1 and keeps *Choose another Stage* (PR #189).
  - **Disposition:** fix now, as a spec reconciliation, together with F1.
- **F3. Device-gated criteria are not met yet.** All three are deferred by a recorded PO decision:
  - 11.1 AC3: GA/BETA measurement at ≥ 95% / ≤ 3 corrections / < 15 s. It is unchecked in PR #190, and `CornerFixtureHarnessTest` is skipped because `Fixtures/corner` is absent.
  - 11.3 human gate: capture acceptance on a device.
  - 11.3 "within 1 s": measured on the JVM only (PR #191).
  - Tracked as `epic-11-deferred-11.1-device-session-c` and `epic-11-deferred-11.3-device-capture-and-sticker-order` (`sprint-status.yaml:854`, `:912`).
  - **Disposition:** defer (tracked). Nothing ships to Learners: every Epic 11 flag is OFF in release and benchmark (`build-logic/.../policy/FeatureFlagLevels.kt:48-59`).
  - **Lesson:** see A3. The flags must not be raised until these land.

The fourth, Recognize's Placement link (added in `cf8306a`), is not tracked anywhere.
  - **Disposition:** fix now, as one consolidated helper (A1).
  - **Lesson:** each story copied the label logic from the previous one, and no story owned the rule.
