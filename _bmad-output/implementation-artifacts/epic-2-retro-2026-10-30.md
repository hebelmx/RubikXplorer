## Findings

### Spec-to-implementation reconciliation

1. **AD-6 wire-name drift shipped, then was fixed in a separate PR.** AD-6 names the combinators `allOf`/`anyOf` (`ARCHITECTURE-SPINE.md:185`). The story 2.2 spec itself wrote `all-of`/`any-of` (`spec-2-2-…md:31,34,37`), the implementation followed the spec, and the deviation was logged only as a "residual risk" in the 2.2 Auto Run Result. It was corrected after merge by `b95eee1` (PR #18, 11 files). Disposition: **accept** (instance fixed). Upstream lesson: story-spec authoring dropped a binding AD identifier, and the review loop treated a known AD deviation as a residual risk instead of a blocker → action item 5.
2. **Non-chrome Learner text in `strings.xml` grew during the epic.** The epic constraint is "`strings.xml` holds navigation chrome only" (`epic-2-context.md`, Requirements). Story 2.1 deferred the pre-existing violation (`spec-2-1-…md:130`), but Epic 2 added more Learner copy there: `learn_empty` "No lessons yet.", `learn_error` (`60bfb98`, story 2.5) and `lesson_moves_hidden` "Hidden until you ask for a hint." (`6c3cb2f`, story 2.6) in `app/src/main/res/values/strings.xml`. The `checkLearnerText` gate does not catch it because it only scans source literals. Disposition: **defer** → action item 3. Upstream lesson: the chrome-vs-Learner-text boundary has no gate.
3. **`tutor-config.json` ships empty (`{}`).** Story 2.7 AC 3 reads "tutor configuration values needed so far … live in `tutor-config.json`, not code". The implementer took reading "no tutor value has a consumer before Epic 4" (`spec-2-7-…md`, Auto Run Result, Residual risks). The file is loaded strictly, schema-checked and hashed (`core/domain/src/main/resources/content/tutor-config.json`, `ContentLoader.kt`). Disposition: **accept**, pending the human answer in Open questions.
4. **Content-validator gaps deferred by 2.4/2.5 were closed in 2.7.** Deferred at `spec-2-4-…md:113,124` and `spec-2-5-…md:160-162` (demonstration vs. steps, empty or no-op steps, zero-step Lesson). `ContentValidator` now rejects them (`spec-2-7-…md` Summary; `ContentValidatorTest` 16 tests). The validated `ShippedLessonPathsTest` (43 tests) drives every shipped Lesson to its predicate. Disposition: **accept** (resolved; a positive cross-story finding).

### Cross-story boundaries (inline adversarial / edge-case lens)

5. **Test me labels taught insert Moves Harmful (2.6 rule × 2.7 content).** `MoveFeedback.classify` compares whole-Objective `progress` before vs. after (`core/domain/src/main/kotlin/dev/rubikxplorer/domain/tutor/MoveFeedback.kt:33-44`; called for every commit at `Reduce.kt:60-66`). The opening Move of an authored corner insert (`R'`, `B'`, `U'`) temporarily lifts a solved piece, so a Learner following the taught path in Test me is told "That moved a piece you need". This was deferred in 2.7 (`spec-2-7-…md:110`, medium) and rejected for change in 2.6 as intent-fixed. The planned fix is Story 4.2's Diagnosis, but 4.2 as written replaces *copy*, not the *classifier* (`MoveFeedback.kt:11`). Exposure is debug-only today because release keeps `TEST_ME=OFF` (`spec-2-6-…md` Residual risks). Disposition: **defer**, with a planning change → action item 2.
6. **Intermediate steps advance only on the exact authored path state.** `Tutor.decide` sets `advance = satisfied || current == pathState(lesson, entry, stepIndex + 1)` (`core/domain/src/main/kotlin/dev/rubikxplorer/domain/tutor/Tutor.kt:33-34`). In *Let me try* / *Test me* on a multi-step Lesson, a Learner who reaches a step's goal another way keeps the earlier step card until the whole Completion Predicate is met. Completion itself stays predicate-decided (the AC holds), but step guidance can lag the cube. Undo past a step boundary likewise leaves the card on the later step (`spec-2-5-…md` Residual risks). Spec-fixed in 2.5 and rejected there. Disposition: **accept** for Epic 2, revisit with Epic 4's `TutorDecision` work (folded into action item 2).
7. **Late Reset confirmation can re-open in a new Lesson.** `confirmed()` re-offers any overtaken confirmation when the session has unsaved steps (`core/application/src/main/kotlin/dev/rubikxplorer/application/session/Reduce.kt:122-131`), without checking that it belongs to the current Lesson. This was carried as an accepted residual risk across both 2.3 review passes (`spec-2-3-…md` Auto Run Result and follow-up). Disposition: **defer** (low; Epic 6 snapshot work touches the same path).
8. **Presentation ordering with concurrent callers.** Deferred in 2.3 (`spec-2-3-…md:135,156`). Story 2.5 added the only production caller and a net-vs-session equality test over Move/Undo/Redo/Reset (`spec-2-5-…md:115`). The concurrent-caller case itself has no test. The 2.3 dialog-drops-Snap deferral (`spec-2-3-…md:171,181`) was resolved by `ResetConfirmation.onTransition` in 2.5 (`spec-2-5-…md:72`). Disposition: **accept** (no concurrent caller exists).
