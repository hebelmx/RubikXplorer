## Intent

**Problem:** Quick Scan's new pure-JVM continuous facelet pipeline (`FaceLatticeFitter` + `ContinuousFaceletMapper` from Story 10.30) has no on-device LiteRT v2 INT8 sticker-center detector, `build-logic` couples `QUICK_SCAN` to the legacy `app/src/camera/corner/` 7-keypoint model (`corner_keypoints.tflite`), and Story 10.23's retired debug shadow sticker reader (`sticker_reader.tflite`, `CapturedFaceObserver`) still clutters debug builds and `GuidedScanActivity`.

**Approach:** Split `build-logic` so `QUICK_SCAN` composes `app/src/camera/continuous/` (`sticker_centers_v2_int8.tflite`, `378,288 B`, LiteRT `2.3.2`) while `CASE_RECOGNITION` alone composes legacy `app/src/camera/corner/`, update `CheckCameraSizeTask` to project the `0.11.0` `CASE_RECOGNITION=OFF` release without double-counting, cleanly retire the Story 10.23 shadow reader while retaining its non-debuggable release guard, promote reproducible clean-room provenance into `tools/center-model/`, wire `LiteRtStickerCenterDetector` + `ContinuousFaceSampler` behind an optional `@BindsOptionalOf` `StickerCenterDetector` seam feeding `FaceLatticeFitter` and `ContinuousFaceletMapper`, and verify NFR-11 size (`< 30,000,000 B`), 16 KB ELF alignment, PC-to-Android peak parity, and R8 latency gates on Lenovo TB128XU and Galaxy S24 FE.

Refs (binding): FR-22 · NFR-5, NFR-8, NFR-11 · AD-9, AD-13, AD-14, AD-15, AD-18 · OQ-7 · PR #363, PR #366 · SCP 2026-11-24 continuous-quick-scan.

## Boundaries & Constraints

**Always:**
- Keep `CAMERA_SCAN`, `QUICK_SCAN`, `PLACEMENT`, and `CASE_RECOGNITION` **OFF** in default `release` and `benchmark` build types (`FeatureFlagLevels.byBuildType`); keep `QUICK_SCAN = BETA` in `debug`; keep opt-in `cornerR8` (`-Pcubentia.cornerR8=true`) composing **both** `continuous` and `corner` model sets so `LiteRtCornerDetectorDeviceTest` and `CiWorkflowTest` stay green.
- Place all `org.tensorflow.lite.Interpreter` / `Interpreter.Options` calls exclusively inside `app/src/camera/` (`app/src/camera/continuous/` and legacy `app/src/camera/corner/`); never inside `app/src/main/`, `:core:*`, or `androidTest`.
- Exclude `com.google.android.play:ai-delivery` on LiteRT, keep `noCompress += "tflite"`, and remove `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_DATA_SYNC` in `app/src/camera/continuous/AndroidManifest.xml` so AD-13 `ManifestPolicy` passes when `CASE_RECOGNITION=OFF`.
- Never persist, write to disk, or transmit any camera frame (AD-13); run all inference off the main thread on XNNPACK CPU with **2 threads**.
- Keep `ShadowReaderPolicy` and `CheckShadowReaderTask` enforcing the non-debuggable release guard against any `sticker_reader*.tflite` asset or `dev/cubentia/app/camera/sticker/` class; keep `tools/sticker-model/` archived untouched.
- Keep `checkLearnerText` clean: no multi-word Learner prose literals in `src/main` or `src/camera` production Kotlin; no `INTERNET` permission or denylisted SDKs.
- Keep `app/src/camera/continuous/assets/sticker_centers_v2_int8.tflite` byte-exact (`378,288 B`, SHA-256 `d18fb2c2fe2bb975cf646877f811718c16775ce6bcde907f12547d143174be7c`).

**Never:**
- Never edit `_bmad-output/planning-artifacts/`, `_bmad/`, `.agents/skills/`, or files outside `/mnt/e/Dynamic/IndFun/RubikXplorer-story-10-31`.
- Never wire `ContinuousQuickScanScreen` or delete 2-corner Quick Scan UI (`QuickScanCoordinator` / `CornerLocator` / `CornerReader` / `CornerGuide`) — that belongs to Story 10.32.

- Never make `build` depend on `detekt` (AD-14), never add `kotlin("android")` or `kapt`.

## Design Notes

- **Direct YUV→`UINT8[1,256,256,3]` letterbox & exact PC parity:** Compute `uprightW`/`uprightH` from `YuvFrame` crop bounds (`right - left`, `bottom - top`) swapped when `rotationDegrees % 180 != 0`. Compute `scale = min(256.0 / uprightW, 256.0 / uprightH)`, `nw = round(uprightW * scale)`, `nh = round(uprightH * scale)`, `left = (256 - nw) / 2`, `top = (256 - nh) / 2`. Zero-fill the reusable `ByteArray(256 * 256 * 3)` border and map each destination `(dx, dy)` inside `[left, left+nw) × [top, top+nh)` using center-aligned bilinear coordinates (`srcX = (dx - left + 0.5) * uprightW / nw - 0.5`, clamped to `[0, uprightW - 1]`), matching PIL `Image.BILINEAR` so exact RGB-still parity matches `corner-peaks-parity.json` to sub-pixel precision while live YUV frames convert directly via BT.601 without allocating a `Bitmap`.
- **Fast allocation-light `ContinuousFaceSampler`:** Reuse a `ByteArray(96 * 96 * 3)` warp buffer and `FloatArray` scratch buffers across frames inside `ContinuousFaceSampler` (single-threaded on `analyzerExecutor`), stepping the projective homography `H: [0..95]² → upright crop` incrementally along each scanline (`xNum += h00`, `yNum += h10`, `wDen += h20`) to keep total sampling time `< 2 ms` per 3-face frame on Lenovo TB128XU while reproducing `pc_spike/mapper.py` L174–281 (3×3 Laplacian sharpness, logo-tolerant 3-of-4 center corners, inner-48% non-center cells, glare/occlusion weights).
- **Opt-in `release011` build type for real minified `0.11.0` size verification:** Mirrors `cornerR8` (`-Pcubentia.release011=true`, absent from default builds, `initWith(release)`, `release011` levels = `CAMERA_SCAN=GA, PLACEMENT=BETA, QUICK_SCAN=BETA, CASE_RECOGNITION=OFF`, NO `CORNER_R8_TEST_RULES`, registers `checkRelease011Size`), allowing both Story 10.31 and Story 10.33 to measure the exact Play-delivered minified `0.11.0` AAB/APK size (`< 30,000,000 B`) and ELF/manifest/shadow/classpath gates while keeping default `release` 100% camera-OFF until Story 10.11.
- **`CheckCameraSizeTask` no-double-counting logic:** In `ReleaseConventionPlugin`, compute `releaseHasCamera = flagLevels.isCameraEnabled(RELEASE)` and `releaseHasContinuous = flagLevels.isContinuousModelEnabled(RELEASE)`:
  - `cameraClasses`: always exclude `CameraSizePolicy.debugOnlyClassGlobs` and `CameraSizePolicy.legacyCornerClassGlobs` (`dev/cubentia/app/camera/corner/**`). When `!releaseHasCamera`, include `dev/cubentia/app/camera/**/*.class`; when `releaseHasCamera && !releaseHasContinuous`, include only `dev/cubentia/app/camera/continuous/**/*.class`; when `releaseHasContinuous`, include nothing.
  - `cameraAssets`: include `src/camera/assets` only if `!releaseHasCamera`; include `src/camera/continuous/assets` only if `!releaseHasContinuous`; never include `src/camera/corner/assets`.
  - `cameraRuntime`: `CheckCameraSizeTask.additionalCameraComponents(debug, release)` already subtracts modules present in `release`.
