## Top corrections (priority order)

1. **min2phase is not cleanly MIT.** The source headers are GPLv3-only, there is no LICENSE file, and GitHub reports no license. The MIT text appears only in the README. Make OQ-4 a blocker before vendoring. (https://raw.githubusercontent.com/cs0x7f/min2phase/master/src/Search.java)
2. **AGP latest stable is 9.5.0 (2026-10-28), not the 9.4 line.** It needs Gradle ≥ 9.6.0 and JDK 17. (https://developer.android.com/build/releases/agp-9-5-0-release-notes)
3. **AGP 9 built-in Kotlin.** Never apply `kotlin("android")`. AGP bundles KGP 2.2.10, so pin KGP 2.4.21 on the root classpath or the app compiles with 2.2.10. (https://developer.android.com/build/migrate-to-built-in-kotlin)
4. **detekt stable (1.23.8) does not support Kotlin 2.4.** Only `dev.detekt` 2.0.0-alpha.x does. Accept the alpha or drop detekt from the AD-14 gate. (https://github.com/detekt/detekt/releases)
5. **Pin the now-known ids.** Compose BOM 2026.09.00 (1.12.1 / M3 1.4.0), CameraX 1.6.2, Room3 3.0.3, Hilt 2.60.1, SceneView 4.62.0, Kotest 6.2.6, JUnit 6.1.x. The memlog's "unverified" entries are now resolved.
