# Cube-specific facelet detectors and annotation sources

**A downloadable detector can locate and name individual colored tiles, but the best documented export missed enough tiles on nine independently published photographs to rule out accepting its predictions on count alone.** For comparing detector geometry against a color-independent baseline, The Kitchen offers clearly labeled, downloadable training images. This review found no validated drop-in model for continuous arbitrary six-face capture on the target phones.

Sources and artifacts were accessed on 2026-11-24. Sizes below count original files, before conversion, compression, or runtime packaging.

## Cross-source check on nine three-face photographs

All nine images in Sean David Reed's November 2023 test split have 27 annotated sticker polygons. The 197-image augmented export comprises 168 training, 20 validation and nine test images. The schema distinguishes six color prefixes with 27 numbered classes each. The original export and data.yaml specify CC BY 4.0, while the hosting card says Apache-2.0. Attribute the original dataset and resolve that discrepancy before redistribution. This is a separately published test split. Independence from Super-Morse's unpublished individual training examples is unknown. [Published split](https://huggingface.co/datasets/seandavidreed/rubiks_cube_segmentation/tree/59141945cb3657f5478c4cb399a2734e1eec804e/test) · [Original export attribution](https://huggingface.co/datasets/seandavidreed/rubiks_cube_segmentation/blob/59141945cb3657f5478c4cb399a2734e1eec804e/README.dataset.txt) · [Class mapping](https://huggingface.co/datasets/seandavidreed/rubiks_cube_segmentation/blob/59141945cb3657f5478c4cb399a2734e1eec804e/data.yaml) · [Hosting card](https://huggingface.co/datasets/seandavidreed/rubiks_cube_segmentation)

We ran the pinned Super-Morse ONNX bytes on CPU. We decoded the published JPEG, letterboxed with black to 640 × 640 and used RGB floats in [0,1]. We kept only sticker classes and applied the publisher's 0.35 score and 0.35 class-agnostic suppression thresholds. No whole-cube candidate exceeded threshold on the nine images. We evaluated all returned stickers before the reference application's nearest-nine filter. We mapped box centers back to original image pixels by removing padding and dividing by the resize scale, and independently multiplied normalized polygon coordinates by the same decoded image dimensions. In score order a detection could claim one previously unmatched polygon if its center lay inside that polygon only. No center landed in multiple polygons. A color match also had to agree with the polygon's color prefix. Of 243 labeled stickers, **118 (48.6%)** had a matched detection center and **104 (42.8%)** also had the correct color. Of the 118 matched, **104 (88.1%)** had the correct color. These are center-in-polygon counts. They do not measure mAP, guided frontal capture, complete cube state, temporal continuity or mobile latency. The nine images include similar scenes. A spot overlay showed the first image's reference polygons followed the visible tiles. A second overlay on the 16_jpg network input (before inverse mapping) showed the 27 predicted boxes clustered horizontally toward the middle of the cube. The cause remains undetermined. A separate OpenCV DNN forward pass reproduced the per-image counts. The result favors testing whether ordered grids stay aligned with observed stickers, including when the raw detection count looks ideal.

To reproduce from this directory, use a temporary environment with Python 3.14, ONNX Runtime 1.32.0, OpenCV 5.1.0.95, NumPy 2.5.5 and PyYAML 6.0.4. The script downloads immutable source revisions into memory and verifies the model hash. It prints the table in the same column order. No external model or media files are included here.

```sh
uv run --no-project --python 3.14 --with onnxruntime==1.32.0 --with opencv-python-headless==5.1.0.95 --with numpy==2.5.5 --with pyyaml==6.0.4 python facelet_probe.py
```
