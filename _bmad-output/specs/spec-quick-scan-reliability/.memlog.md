- (note) User reports sticker color results vary with lighting and suspects white balance contributes.
- (note) Repository code maps the preview guide into camera-frame coordinates in app/src/camera/kotlin/dev/cubentia/app/camera/ViewfinderGrid.kt; this supports intended alignment but does not establish on-device visual correctness.
- (note) app/src/camera/kotlin/dev/cubentia/app/camera/GuidedScanActivity.kt updates detectedCornerQuads from CornerOverlaySmoother; its EMA smooths small changes, clears on detection loss, and snaps on large changes.

- (note) Older evidence records about 920–1050 ms per frame for the replaced Kotlin corner heuristic and Red/Orange uncertainty on shaded faces; those historical figures do not diagnose current user-visible latency.
